# ZAGA — сайт артиста

Статический сайт без сборки: HTML, CSS и JS. Открывается любым веб-сервером.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: первый экран, ближайший концерт, сниппеты, музыка, бренд одежды, контакты |
| `concerts.html` | Концерты: обложка, обратный отсчёт, афиша |
| `video.html` | Видео: премьера и сетка сниппетов |
| `brand.html` | Бренд одежды ТӨРКӨМ: каталог с фильтрами |
| `404.html` | Страница «не найдено» |

## Как обновлять

Все данные в одном файле — `data.js`:

- `CONCERTS` — афиша. Прошедшие даты скрываются сами. `qtickets` — ссылка на событие в Qtickets.
- `MUSIC` — популярные треки и нарезки (`audio/*.m4a`).
- `VIDEOS` — сниппеты (`video/<slug>.mp4`, `<slug>-preview.mp4`, `<slug>.webp`). `featured: true` — премьера на странице «Видео».
- `PRODUCTS`, `COLLAGE` — каталог бренда и вещи для коллажа на главной.
- `CONTACTS` — менеджер, соцсети, проекты.

После правок CSS/JS увеличьте номер `?v=` в ссылках на `styles.css`, `data.js`, `app.js` во всех HTML — так браузеры подхватят новую версию.

## Локальный просмотр

```bash
python -m http.server 5173
```

Затем откройте http://localhost:5173
